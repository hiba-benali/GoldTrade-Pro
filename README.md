# 🏆 Hiba App – Gold Trading & AI Assistant

A full-featured **cross-platform Flutter application** for gold price tracking, portfolio management, and AI-powered investment assistance.

---

## 🚀 Features

- 📊 Real-time gold price tracking (XAU/USD)
- 💼 Portfolio management with profit/loss tracking
- 🤖 AI chatbot advisor (Gemini AI)
- 📈 Interactive charts & analytics
- 🗺️ Map of gold shops (OpenStreetMap)
- 💱 Currency conversion support

---

## 🧠 AI & Services

- Gemini AI for intelligent financial assistance
- Supabase backend (authentication + database)
- External APIs for gold prices and currency rates

---

## 🛠️ Tech Stack

- Flutter (Frontend)
- Supabase (Backend)
- Gemini AI
- OpenStreetMap
- REST APIs

---

## 📁 Project Structure

- `lib/screens/` → App UI screens (Home, Portfolio, Chatbot, etc.)
- `lib/services/` → API & business logic
- `lib/widgets/` → Reusable UI components
- `lib/config/` → Theme & constants
